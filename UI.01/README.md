### This is a Tailwind CSS code block

```tsx
export default function Home() {
  return (
    <h1 className="text-blue-500">
      Apply text color
    </h1>
<div className="bg-red-500">
    Apply background color
  </div>
 <div className="border border-gray-500">
    Apply border color
  </div>
<h1 className="text-3xl">
    Apply font size
  </h1>
 <h1 className="font-bold">
    Set Font Weight
  </h1>
 <p className="leading-8">
    This is an example of setting line height with Tailwind CSS.
  </p>
 <p className="tracking-wide">
    Set letter spacing
  </p>
 <div className="w-64">
    Set element width
  </div>
<div className="h-32">
    Set element height
  </div>
 <div className="min-h-32 max-h-64 overflow-auto">
    Set minimum and maximum height
  </div>
 <div className="min-w-32 max-w-64">
    Set minimum and maximum width
  </div>
  <div className="p-4">
    Apply padding
  </div>
<div className="m-4">
    Apply margin
  </div>
<div className="p-4 m-6">
    Understand spacing scale
  </div>
<div className="w-[420px]">
    Use arbitrary width value
  </div>
<div className="w-[420px] p-4 m-4 bg-blue-500 text-white font-bold">
    Combine multiple utilities
  </div>
  );
}
```

### Apply text color

The `text-blue-500` class applies blue text color to the heading.

### Apply background color

The `bg-red-500` class applies red background color to the heading.

### Apply border color

The `border-gray-500` class applies gray border color to the heading.

### Apply font size

The `text-3xl` class applies font size to the heading.

### Apply font weight

The `font-bold` class applies font weight to the heading.

### Set line heights

The `leading-8` class applies line height to the heading.

### Set tracking wide

The `tracking-wide` class applies letter spacing to the heading.

### Set element width

The `w-64` class applies element widht to the heading.

### Set element height

The `h-32` class applies element height to the heading.

### Set minimum/maximum height

The `min-h-32 max-h-64` class applies minimum/maximum hieght to the heading.

### Set minimum/maximum width

The `min-w-32 max-w-64` class applies minimum/maximum width to the heading.

### Apply padding

The `p-4` class applies padding to the heading.

### Apply margin

The `m-4` class applies margin to the heading.

### Understand spacing scale

The `p-4 m-6` class applies spacing scale to the heading.

### Use arbitrary value such as w-[420px]

The `w-[420px]` class applies w-[420px] the heading.

### Combine multiple utilities correctly

 The `w-[420px] p-4 m-4 bg-blue-500 text-white font-bold` class applies  multiple utilities correctl the heading.
